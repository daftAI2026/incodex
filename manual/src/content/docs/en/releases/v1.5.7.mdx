### Changelog

1. **Update confirmation**: Successful `inc update` upgrades now report the verified installed CLI version after Runtime publication succeeds, using the same output across macOS script, Homebrew and Windows installs.

Upgrade with `inc update`. The CLI that starts the update prints its result, so an upgrade initiated by v1.5.6 may still show the old success message; verify the installed version with `inc --version`. Same-version messages, partial-failure handling, Runtime activation behavior and existing platform limitations are unchanged.
