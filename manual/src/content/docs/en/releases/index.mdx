The documented stable baseline for this manual is **v1.5.1**. Guides explain current usage; the entries below preserve changes and limitations at each release.

- [v1.5.1 · 2026-10-19](/en/releases/v1.5.1/): macOS `inc`-alias install fix, cold-start permission snapshots, restored-app Screen Recording remains unverified, and update guidance.
- [v1.5.0 · 2026-10-19](/en/releases/v1.5.0/): Registered macOS update recovery, dual-permission setup, and permission rechecks.
- [v1.4.0 · 2026-10-10](/en/releases/v1.4.0/): Compatible Runtime hot updates and generation diagnostics.
- [v1.3.4 · 2026-10-10](/en/releases/v1.3.4/): macOS remote-control device-key compatibility.
- [v1.3.2 · 2026-10-09](/en/releases/v1.3.2/): Stable masked windows and stale Store-package uninstall recovery.
- [v1.3.1 · 2026-10-09](/en/releases/v1.3.1/): macOS launch compatibility and a clean documentation audit.
- [v1.3.0 · 2026-10-03](/en/releases/v1.3.0/): first sidebar Pin entry and equivalent command aliases.
- [v1.2.1 · 2026-10-02](/en/releases/v1.2.1/): startup and close cleanup, official notifications and tooltips, unified hat rendering, and Windows hardening.
- [v1.1.0 · 2026-09-29](/en/releases/v1.1.0/): native permission setup, layout inheritance, and installation compatibility.

For older versions, see the [complete GitHub release history](https://github.com/daftAI2026/incodex/releases). This section lists published releases; development branches and test candidates are not stable releases.

Read the [upgrade guide](/en/updates/) first. Usually, start with `inc update`. Registered default macOS installs attempt recovery after Sparkle updates; reinstall against the current app if integration remains missing. Windows Store updates still require manual installation against the current package generation.
