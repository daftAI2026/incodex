The documented stable baseline for this manual is **v1.3.1**. Guides explain current usage; the entries below preserve changes and limitations at each release.

- [v1.3.1 · 2026-10-09](/en/releases/v1.3.1/): macOS launch compatibility and a clean documentation audit.
- [v1.3.0 · 2026-10-03](/en/releases/v1.3.0/): first sidebar Pin entry and equivalent command aliases.
- [v1.2.1 · 2026-10-02](/en/releases/v1.2.1/): startup and close cleanup, official notifications and tooltips, unified hat rendering, and Windows hardening.
- [v1.1.0 · 2026-09-29](/en/releases/v1.1.0/): native permission setup, layout inheritance, and installation compatibility.

For older versions, see the [complete GitHub release history](https://github.com/daftAI2026/incodex/releases). This section lists published releases; development branches and test candidates are not stable releases.

Read the [upgrade guide](/en/updates/) first. Usually, start with `inc update`. An outdated app loader or an official Codex update also requires reinstalling integration against the current package.
