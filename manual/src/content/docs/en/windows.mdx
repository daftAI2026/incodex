## The installed control

After `incodex install`, launch the **official Codex icon** as usual. The hat-glasses control appears in the upper-left toolbar, on the same row as the Codex title, notification bell, and Search.

This is a position diagram, not a screenshot. Click the hat-glasses control, or press **Shift+Command+N** on macOS / **Ctrl+Shift+N** on Windows. On macOS, the installed integration also exposes the action in the official Dock menu and the existing menu-bar status menu.

Hover over the normal-window control for “Open incognito window”. In an incognito window, hover changes the hat to a circle-x with an exit tooltip. Clicking it closes that private window; it does not start a nested window.

## Optional sidebar entry

On supported layouts, a second hat-glasses control appears in the left navigation rail. Use either control to open or close the private window. The toolbar control remains available when the sidebar entry does not appear.

The sidebar entry has been verified on macOS. It has not yet been verified in a running Windows Store Codex window.

## The private window

The separate window uses the same login, language, and base configuration. Earlier chats are absent. It follows the main window's size and placement. Its notification appears on the private window's home page only. Dismissing the notification hides the explanation, not the isolation.

`incodex open` also receives the hat-glasses control and banner, whether the official app has the current installed loader or has never been patched.

## Close versus minimize

Normal close removes the isolated home and Chromium profile. **Minimize keeps the session alive**. On macOS, the red button closes; the yellow button minimizes. On Windows, close the isolated window normally.

An unexpected crash, force quit, or shutdown may leave cleanup work. Use [doctor](/en/commands/doctor/) to inspect leftovers; do not delete your official `~/.codex` data.

## Terminal menu

Run `inc` in a terminal. Use arrows or `j/k`, Enter to select, digits to run immediately, `V` for version, and `q` to quit. Without a terminal, no arguments prints help. `inc` and `incodex` are the same program. `--help` and `--version` also accept `-h` and `-V`.
