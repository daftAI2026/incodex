## Install shortcuts

```bash
curl -fsSL https://raw.githubusercontent.com/daftAI2026/incodex/main/scripts/setup-quick-launchers.sh | bash
```

The script writes Raycast commands to `~/Library/Application Support/Raycast/script-commands`. Only when Alfred is detected does it generate a standard `.alfredworkflow` and open Alfred's normal import confirmation.

## Raycast setup

- **v2:** Settings → Script Commands → Add Script Directory.
- **v1:** Settings → Extensions → **+** → Add Script Directory.

Choose the script-commands directory above, then run **Reload Script Commands**.

Settings vary by Raycast version; see the [official Script Commands guide](https://manual.raycast.com/script-commands).

Open launches the private window directly. Status and Doctor use Raycast's fullOutput when it provides a usable TERM; otherwise they launch a supported terminal. `INCODEX_LAUNCHER_APP` can select Terminal, iTerm2, Alacritty, kitty, WezTerm, Ghostty, Hyper, WindTerm, or Warp. A failed selected launch falls back to Terminal.

These shortcuts are optional and macOS-only. See [permissions](/en/permissions/).

**Unreleased macOS change:** the CLI uses WindowServer observation for close/minimize; Accessibility permission is not required. Installed-app permissions remain separate. Published v1.5.5 still uses the earlier terminal/launcher Accessibility check.
