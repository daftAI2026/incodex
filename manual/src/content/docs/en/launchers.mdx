## Finder entry

The macOS alternative `incodex launch` creates **ChatGPT - Inc.app** in your user Applications folder. Its mint-to-lavender hat-glasses icon leaves the official Codex icon untouched. Use **Launch** in the `inc` menu to create or open this normal-window route; **Open** starts a private window directly.

Use `incodex launch --remove --dry-run` to preview entry removal, then `incodex launch --remove` to confirm. This does not uninstall app integration or close Codex. See the [launch guide](/en/commands/launch/) for creation, reuse, removal, and platform limits.

## New icon (not yet in a stable release)

This branch uses the host's current system icon with an **INCODEX** glass plaque at the bottom. It does not copy or modify the official app, and users do not need Icon Composer. ChatGPT and Codex keep their own marks instead of receiving one fixed replacement image.

The next `incodex launch` with the new version regenerates the launcher icon. Recognized older entries remain upgradable and removable; `incodex launch --remove` can remove an owned entry even when its source host is gone. Isolated composition and filesystem tests have passed; visual acceptance of the installed Finder entry is still pending.

## Install shortcuts

```bash
curl -fsSL https://raw.githubusercontent.com/daftAI2026/incodex/main/scripts/setup-quick-launchers.sh | bash
```

The script writes Raycast commands to `~/Library/Application Support/Raycast/script-commands`. Only when Alfred is detected does it generate a standard `.alfredworkflow` and open Alfred's normal import confirmation.

## Raycast setup

- **v2:** Settings → Script Commands → Add Script Directory.
- **v1:** Settings → Extensions → **+** → Add Script Directory.

Choose the script-commands directory above, then run **Reload Script Commands**.

Settings vary by Raycast version; see the [official Script Commands guide](https://manual.raycast.com/script-commands).

Open launches the private window directly. Status and Doctor use Raycast's fullOutput when it provides a usable TERM; otherwise they launch a supported terminal. `INCODEX_LAUNCHER_APP` can select Terminal, iTerm2, Alacritty, kitty, WezTerm, Ghostty, Hyper, WindTerm, or Warp. A failed selected launch falls back to Terminal.

These shortcuts are optional and macOS-only. See [permissions](/en/permissions/).

**macOS:** the CLI uses WindowServer observation for close/minimize; Accessibility permission is not required. Installed-app permissions remain separate.
