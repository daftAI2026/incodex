`inc` and `incodex` are interchangeable executable names. The unreleased experiment accepts only `perm`; `accessibility` and `permissions` are not command aliases. This rename is not included in stable v1.4.0.

## Stable v1.4.0: Accessibility check

Stable v1.4.0 uses `incodex accessibility` or `inc accessibility`. It checks ChatGPT Accessibility and opens the shared guide only when access is missing. It works with a verified Incodex installation or the restored official `/Applications/ChatGPT.app`. It does not patch or uninstall the app. A TCC reset is possible only after you choose Allow in the guide. Skip, close, or interruption leaves setup available for a later retry. This is not the terminal permission required by `open`.

## Unreleased experiment: `perm`

Use `incodex perm` or `inc perm` to check ChatGPT Accessibility and Screen Recording. The command works with a verified Incodex installation or the restored official `/Applications/ChatGPT.app`; it does not patch or uninstall the app. The guide shows these permissions as separate rows. If fresh probes do not confirm both permissions as granted, explicit `perm` opens the shared guide. An `unknown` result remains `unknown`; it is not treated as denied. The command completes only after fresh probes confirm that both permissions are granted. If host or Runtime evidence is unavailable, Screen Recording remains `unknown`, not granted or denied.

Each granted row stays visible with its localized completion label and check mark (`Done ✓` in English). Skip, close, or interruption leaves setup available for a later retry. Only choosing Allow can reset ChatGPT's old Accessibility registration. Screen Recording is not a prerequisite for `incodex open`; see [Permissions](/en/permissions/) for probe and manual Settings steps.

## Examples

```bash
incodex perm
inc perm
```
