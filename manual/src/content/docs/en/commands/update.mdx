`inc` and `incodex` are interchangeable for this command and all its flags.

```bash
inc update [--dry-run]
```

Homebrew updates through Homebrew; macOS script installs and managed Windows installs use their verified platform installer. Then the newly installed CLI publishes its bundled Runtime. It never patches Codex. Source checkouts receive git pull / cargo install guidance. If CLI update succeeds but Runtime fails, the result is partial success; the CLI is not rolled back. A same-version script update still repairs Runtime.

### Success message

Successful upgrades report the verified installed CLI version as `🎉 Updated to version X.Y.Z!`, after Runtime publication succeeds. `X.Y.Z` is a placeholder for the actual installed version, not the version of the old running CLI. The CLI that started the update prints the result, so an upgrade started by an older CLI can still show its earlier success message. Same-version and newer-local-version messages remain unchanged. This message confirms installation and Runtime publication, not activation of every running window; compatible changes can apply live, while other changes load on the next normal start.

## Flags

| Flag | Meaning |
| --- | --- |
| `--dry-run, -n` | Show channel and plan without updating. |

## Examples

```bash
inc update --dry-run
inc update
```
