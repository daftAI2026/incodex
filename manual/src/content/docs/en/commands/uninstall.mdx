`inc` and `incodex` are interchangeable for this command and all its flags.

```bash
incodex uninstall [--yes] [--dry-run]
```

macOS verifies and restores the matching official backup. It does not overwrite an already-upgraded official package with an old snapshot. Windows removes only Incodex's registration and observer; the Store package stays unchanged. Fully quit Store Codex before removal. The CLI remains installed.

## Unreleased fix: post-uninstall permission guide

This behavior is not part of the published v1.5.0 baseline. Real-app acceptance is pending. After macOS restores the unmodified official app, Screen Recording has no Incodex probe. Dropping the current ChatGPT app into the open System Settings window sends a receipt only; it does not prove that the permission row is selected, its switch is enabled, or access is `granted`.

If Accessibility is already granted, the guide closes and Screen Recording remains `unknown`. Check the current ChatGPT entry in System Settings. If Accessibility is not granted, its permission actions stay available. See [macOS permissions](/en/permissions/).

## Flags

| Flag | Meaning |
| --- | --- |
| `--yes` | Skip confirmation; required without a terminal. |
| `--dry-run, -n` | Preview removal. |
| `--app <path>` | macOS only: restore a specific .app. |
| `--clone` | macOS only: restore the scratch copy. |

## Examples

```bash
incodex uninstall --dry-run
incodex uninstall
```

Use `incodex uninstall --help` for your installed version. [Window guide](/en/windows/) · [Permissions](/en/permissions/) · [Privacy](/en/privacy/)
