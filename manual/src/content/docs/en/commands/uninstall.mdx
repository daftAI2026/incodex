`inc` and `incodex` are interchangeable for this command and all its flags.

```bash
incodex uninstall [--yes] [--dry-run]
```

macOS verifies and restores the matching official backup. It does not overwrite an already-upgraded official package with an old snapshot. Windows removes only Incodex's registration and observer; the Store package stays unchanged. Fully quit Store Codex before removal. The CLI remains installed.

## Post-uninstall permission guide

After macOS restores the unmodified official app, Screen Recording has no Incodex probe. A confirmed drop into System Settings makes the guide retract its helper instead of waiting for the missing probe. The guide finishes once Accessibility is genuinely granted. Screen Recording remains unverified: check its entry in System Settings; a drop does not prove or grant access. If Accessibility remains missing, continue its permission actions. See [macOS permissions](/en/permissions/).

## Flags

| Flag | Meaning |
| --- | --- |
| `--yes` | Skip confirmation; required without a terminal. |
| `--dry-run, -n` | Preview removal. |
| `--app <path>` | macOS only: restore a specific .app. |
| `--clone` | macOS only: restore the scratch copy. |

## Examples

```bash
incodex uninstall --dry-run
incodex uninstall
```

Use `incodex uninstall --help` for your installed version. [Window guide](/en/windows/) · [Permissions](/en/permissions/) · [Privacy](/en/privacy/)
