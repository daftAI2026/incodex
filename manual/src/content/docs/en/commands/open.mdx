`inc` and `incodex` are interchangeable for this command and all its flags.

```bash
incodex open [--dry-run] [--mask] [--name <text>] [--avatar <local-file>]
```

Launches the official binary with isolated Codex and Chromium homes, then injects the shared hat-glasses control and banner over local CDP. No app copy, patch, or signing. The normal account, language, and base settings are preserved without earlier chats. Normal close burns the private session; minimize retains it. On macOS the launching terminal or launcher needs Accessibility; a dry-run does not.

## Flags

| Flag | Meaning |
| --- | --- |
| `--dry-run, -n` | Print the target, without opening or creating a session. |
| `--mask` | Temporary sidebar/account-menu identity only. |
| `--name <text>` | Requires --mask; quote spaces. Otherwise uses a random two-word name. |
| `--avatar <local-file>` | Requires --mask; regular PNG/JPEG/WebP ≤5 MiB. Otherwise generates an offline avatar. |
| `--app <path>` | macOS only: launch a specific official app. |

## Examples

```bash
incodex open --dry-run
incodex open
incodex open --mask --name "Quiet Otter" --avatar ./avatar.png
```
