`inc` and `incodex` are interchangeable for this command and all its flags.

```bash
incodex open [--dry-run] [--mask] [--name <text>] [--avatar <local-file>] [--app <path>]
```

Launches the official binary with isolated Codex and Chromium homes, then injects the shared hat-glasses control and banner over local CDP. No app copy, patch, or signing. The normal account, language, and base settings are preserved without earlier chats. Normal close burns the private session; minimize retains it.

**macOS:** the CLI uses WindowServer observation for close/minimize; Accessibility permission is not required. Installed-app permissions remain separate.

**Windows, planned for 1.5.11:** default private windows restore the hat-glasses control and banner after a page reload. After upgrading with `inc update`, close and reopen existing private windows to use the fixed CLI.

`open --mask` recognizes the supported avatar-only navigation rail, masks its avatar and the linked account-menu identity, and keeps the sidebar entry stable while the window becomes ready. The sidebar stays avatar-only; the temporary name appears in the linked menu. Full Settings still shows the official account details.

## Flags

| Flag | Meaning |
| --- | --- |
| `--dry-run, -n` | Print the target, without opening or creating a session. |
| `--mask` | Temporary sidebar/account-menu identity only. |
| `--name <text>` | Requires --mask; quote spaces. Otherwise uses a random two-word name. |
| `--avatar <local-file>` | Requires --mask; regular PNG/JPEG/WebP ≤5 MiB. Otherwise generates an offline avatar. |
| `--app <path>` | macOS only: launch a specific official app. |

## Examples

```bash
incodex open --dry-run
incodex open
incodex open --mask --name "Quiet Otter" --avatar ./avatar.png
```
