`inc` and `incodex` are interchangeable for this command and all its flags.

```bash
incodex accessibility
```

**Stable v1.4.0:** macOS only. Explicitly checks ChatGPT Accessibility and opens the shared guide only if access is missing. Works with a verified Incodex installation or restored official `/Applications/ChatGPT.app`. It neither patches nor uninstalls the app. A reset is possible only after choosing Allow. Skip, close, or interruption leaves setup available for a later retry. This is not the terminal permission required by open.

**Unreleased experimental behavior — not included in stable v1.4.0:** The experimental guide shows Accessibility and Screen Recording as separate rows. Each granted row remains visible with its localized completion label and check mark (`Done ✓` in English). The command completes only after fresh probes confirm both permissions are granted. If host or Runtime evidence is unavailable, Screen Recording remains `unknown`, not granted or denied. Screen Recording is not a prerequisite for `incodex open`; see [Permissions](/en/permissions/) for the probe and manual Settings steps.

## Examples

```bash
incodex accessibility
```

Use `incodex accessibility --help` for your installed version. [Window guide](/en/windows/) · [Permissions](/en/permissions/) · [Privacy](/en/privacy/)
