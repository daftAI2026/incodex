`inc` and `incodex` are interchangeable for this command and all its flags.

```bash
incodex accessibility
```

macOS only. Explicitly checks ChatGPT Accessibility and opens the shared guide only if access is missing. Works with a verified Incodex installation or restored official `/Applications/ChatGPT.app`. It neither patches nor uninstalls the app. A reset is possible only after choosing Allow. Skip, close, or interruption leaves setup available for a later retry. This is not the terminal permission required by open.

## Examples

```bash
incodex accessibility
```

Use `incodex accessibility --help` for your installed version. [Window guide](/en/windows/) · [Permissions](/en/permissions/) · [Privacy](/en/privacy/)
