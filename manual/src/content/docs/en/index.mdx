Incodex is an unofficial local add-on for the OpenAI Codex desktop app. Keep your usual login, language, and base settings; start a separate conversation without importing your everyday chat history.

## Launcher icon

<figure>
  <img src="/incodex/images/launcher-icon-native-preview.png" width="240" loading="lazy" alt="ChatGPT launcher icon with an INCODEX plaque" />
  <figcaption>Icon example: ChatGPT icon with an INCODEX plaque.</figcaption>
</figure>

Run `inc update`, then `incodex launch` to create or refresh `/Applications/ChatGPT - Inc.app`.

The launcher follows the selected ChatGPT or Codex Dock icon style. If that icon resource is unavailable, it falls back to the host's file icon. Run `incodex launch` again after changing the Dock choice; Incodex does not watch for changes in the background. This update does not require re-signing, reinstalling, or restarting the host. See the [macOS launcher guide](/en/launchers/) for the migration and refresh steps.

## What this manual covers

These pages describe **Incodex 1.5.10**. macOS supports Apple Silicon and Intel; Windows supports x86_64 with the current user's Microsoft Store Codex package. Linux is unsupported. Windows automatic repair after a real Store update remains experimental; the first cold launch after that update has not been verified. The remaining macOS 26 permission-guide check is the full two-row flow: grant missing permissions in System Settings, return to the installed ChatGPT window, and confirm that fresh probes close the guide.

Normal close removes Incodex's isolated local session. This is not forensic erasure and does not prevent files, remote services, or connected tools from retaining data. Read the [privacy boundary](/en/privacy/) before relying on it.
