Incodex is an unofficial local add-on for the OpenAI Codex desktop app. Keep your usual login, language, and base settings; start a separate conversation without importing your everyday chat history.

## Start here

- [Install the CLI](/en/installation/), then use `incodex open` for a window without patching the app.
- [Enable the in-app control](/en/commands/install/) if you want to launch from the official Codex icon.
- [Find the control and close the window](/en/windows/).
- [Look up every command](/en/commands/).

## What this manual covers

These pages describe **Incodex 1.3.4**. macOS supports Apple Silicon and Intel; Windows supports x86_64 with the current user's Microsoft Store Codex package. Linux is unsupported. Windows automatic repair after a real Store update remains experimental; the first cold launch after that update has not been verified.

Normal close removes Incodex's isolated local session. This is not forensic erasure and does not prevent files, remote services, or connected tools from retaining data. Read the [privacy boundary](/en/privacy/) before relying on it.
