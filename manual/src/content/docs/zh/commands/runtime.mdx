`inc` 和 `incodex` 在这个命令及全部参数中通用。

```bash
incodex runtime
```

把验证过的 Incodex 资产发布到 `~/.incodex/runtime/`，不修改或重新签名官方应用。兼容更新可在受支持的运行中窗口激活，其他变化重开后加载；不安装应用入口，也不升级旧加载器。通常 inc update 自动执行这一步。

## macOS 兼容 Runtime 更新

普通 macOS Codex 进程使用新版 Runtime 启动后，如果发布的新一代只改 UI 注入脚本或受支持的主进程动作模块，现有受支持窗口会自动更新。所有窗口确认候选后才提交；激活失败会尝试回退到上一版 UI。发布不会刷新官方页面或重启 Codex。

已有集成运行 `inc update`，更新 CLI 并发布内置 Runtime。将既有临时签名的默认 macOS 集成迁移到稳定本地签名身份时，显式运行一次 `incodex uninstall`，再运行 `incodex install`。新身份可能需要首次授权。动作模块负责打开无痕窗口和配置菜单；授权检查、启动/会话所有权和原生句柄仍由现有控制器持有。新请求使用已提交的动作版本，进行中的请求使用其开始时的版本完成。其他主进程代码、preload、原生组件或其他外部资产变化仍需要重开。已安装加载器变化需要执行 `incodex install`，仅重开不会替换 ASAR 内的加载器。已经打开的隐身窗口保留原隐私实现，直到正常关闭。

macOS 控制器会在现有启动日志中分别记录已验证的磁盘发布、启动控制器、已提交动作模块和逐窗确认的版本，并用宿主 PID 与进程启动身份关联。窗口未确认或验证失败会明确保留；仅有磁盘发布成功或 CLI 状态不能证明已经激活。

Runtime 发布或官方更新恢复成功后，macOS 会调度一次绑定代际的原生权限检查。新鲜读数确认两项均已授权时不弹卡；确认缺权时打开共用向导；只有 `unknown` 时保持待确认。原生 CLI 独占向导，用户授权没有倒计时。新 Runtime 对旧的未完成请求只做交接，不在 Electron 内弹卡或重置权限。旧控制器不会追溯获得新宿主代码；首次迁移须经过正常进程生命周期。macOS 26 仍待验证已安装 ChatGPT 窗口中的完整双行向导：在系统设置中授予缺失权限，返回 ChatGPT，并确认新鲜探针通过后向导关闭。跨签名授权连续性也仍待验收。

## Windows 已安装窗口的 Runtime 更新

Runtime 同步还会交接同一安装登记下待处理的 Store 更新记录，包括版本已最新时的修复；保留原 helper 与预留的目标身份。记录无法核验时报告失败并保留现场，不删除记录来强行继续。这不保证已错过注入的运行中窗口能补上帽子，也不代表下一次真实 Store 更新已验收。

若此前更新已留下属于其他安装操作的记录，Runtime 同步会报告失败并保留记录；请正常退出 Codex，先运行 `incodex uninstall`，再运行 `incodex install`，显式刷新集成；此迁移不算自动更新成功。

已有启用中的集成时，必须先卸载再安装。请按 [Windows v1.5.4 迁移指南](/zh/updates/#windows-v154)预览并执行卸载、安装；显式迁移不算自动更新通过。

Windows 已安装控制器通过现有 helper，把兼容的 UI 注入脚本和共享业务动作更新应用到正在运行的已安装窗口。取得真实页面确认、重新核对选中版本后，才提交动作版本并确认提交；失败时尝试同时回退两者。新请求使用已提交的动作版本，进行中的请求使用其开始时的版本完成。已安装窗口的桥仍只允许打开无痕窗口。不重启 Codex，也不刷新页面。这条已安装应用路径已通过真实应用热更新验收；真实 Windows Store 升级后的自动恢复仍属实验能力。

旧 helper 没有这个控制器。首次启用需要等 Codex 正常退出后，显式执行一次 `incodex install`。完成首次设置后，兼容的 UI 与动作更新无需退出应用或刷新页面。其他 Runtime 资产变化需要重开，原生 helper 变化需要显式安装。已经打开的隐身窗口保留原隐私实现，直到正常关闭。

更新现有 Homebrew、脚本或 Windows 受管理安装时，运行 `inc update` 更新 CLI 并发布其内置 Runtime。源码安装先在代码仓运行 `git pull`，再执行 `cargo install --locked --path crates/incodex-cli` 和 `incodex runtime`。既有临时签名的默认 macOS 集成须按[升级指南](/zh/updates/)显式卸载并安装一次。重装 `--app <path>` 或 `--clone` 目标时，带上原选项。只使用 `incodex open` 的用户更新后重开隐身窗口即可，无需安装集成。

## 参数

| 参数 | 含义 |
| --- | --- |
| `--dry-run` | 预览 Runtime 发布，不写入文件。 |

## 示例

```bash
incodex runtime --dry-run
incodex runtime
```
