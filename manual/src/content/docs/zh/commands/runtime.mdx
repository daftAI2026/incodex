`inc` 和 `incodex` 在这个命令及全部参数中通用。

```bash
incodex runtime
```

把验证过的 Incodex 资产发布到 `~/.incodex/runtime/`，不修改或重新签名官方应用。彻底退出再重开以加载选中的一代；不安装应用入口，也不升级旧加载器。通常 inc update 自动执行这一步。

## 未发布：macOS 兼容 UI 更新

普通 macOS Codex 进程使用新版 Runtime 启动后，如果发布的新一代只改 UI 注入脚本，现有受支持窗口会自动更新。所有窗口确认候选后才提交；激活失败会尝试回退到上一版 UI。发布不会刷新官方页面或重启 Codex。

旧 Runtime 首次升级仍需彻底退出重开。主进程、preload、加载器、原生组件或其他资产变化也需要重开。已经打开的隐身窗口保留原隐私实现，直到正常关闭。Windows 自动重新激活单独验收。上方已发布的 v1.3.4 行为仍是稳定版基线。

## 参数

| 参数 | 含义 |
| --- | --- |
| `--dry-run` | 预览发布（Windows 帮助中列出，macOS 原生 CLI 也支持）。 |

## 示例

```bash
incodex runtime --dry-run
incodex runtime
```

用 `incodex runtime --help` 查看已安装版本的帮助。[窗口使用](/zh/windows/) · [权限](/zh/permissions/) · [隐私边界](/zh/privacy/)
