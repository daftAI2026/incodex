`inc` 和 `incodex` 在这个命令及全部参数中通用。

```bash
inc update [--dry-run]
```

Homebrew 沿用 Homebrew，macOS 脚本与受管理 Windows 安装使用经过验证的平台安装器。随后由新 CLI 发布内置 Runtime，不改 Codex。源码安装提示 git pull / cargo install。CLI 更新成功但 Runtime 失败时报告部分成功，不回滚 CLI；脚本渠道同版本更新也会修复 Runtime。

### 成功提示

自 v1.5.7 起，升级完成且 Runtime 发布成功后，显示 `🎉 Updated to version X.Y.Z!`。`X.Y.Z` 代表已验证的实际安装版本，不是仍在运行的旧 CLI 版本。结果由发起更新的 CLI 打印，因此从 v1.5.6 首次升级时仍可能看到旧成功提示。同版本和本地版本较新的提示不变。成功提示确认安装与 Runtime 发布，不代表每个运行窗口都已激活新版；兼容变化可热生效，其他变化在下次正常启动加载。

### 尚未发布的 Windows 修复

后续 Windows 修复会给已验证的受管 CLI 文件设置旧版已安装 helper 要求的同一私有 ACL。同摘要安装器重跑只修复元数据，不替换不可变 EXE；同版本不同内容仍拒绝覆盖。Runtime 发布前会验证指定的受管代际，再选择它。这不代表原生 helper 已换代，也不代替下一次真实 Store 更新验收；这些生命周期结果单独记录。

## 参数

| 参数 | 含义 |
| --- | --- |
| `--dry-run, -n` | 展示渠道和计划，不更新。 |

## 示例

```bash
inc update --dry-run
inc update
```
