`inc` 和 `incodex` 在这个命令及全部参数中通用。

```bash
incodex accessibility
```

**稳定版 v1.4.0：**仅 macOS。主动检查 ChatGPT 辅助功能，缺失时才打开共享向导。可用于已验证的 Incodex 安装或恢复后的官方 `/Applications/ChatGPT.app`；不改包、不卸载。只有选择允许后才可能重置登记。跳过、关闭或中断后可重试。这不是 open 所需的终端权限。

**未发布实验行为，不包含在稳定版 v1.4.0：**实验向导将辅助功能和屏幕录制分成两行。已授权行仍显示本地化完成标签与 `✓` 标记（英文为 `Done ✓`）。只有新鲜探针确认两项权限均为 `granted`，命令才完成。宿主或 Runtime 证据不可用时，屏幕录制状态保持 `unknown`，不标成已授权或已拒绝。屏幕录制不是 `incodex open` 的前置条件；探针和系统设置步骤见[权限指南](/zh/permissions/)。

## 示例

```bash
incodex accessibility
```

用 `incodex accessibility --help` 查看已安装版本的帮助。[窗口使用](/zh/windows/) · [权限](/zh/permissions/) · [隐私边界](/zh/privacy/)
