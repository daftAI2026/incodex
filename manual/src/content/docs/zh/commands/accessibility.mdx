`inc` 和 `incodex` 在这个命令及全部参数中通用。

```bash
incodex accessibility
```

仅 macOS。主动检查 ChatGPT 辅助功能，缺失时才打开共享向导。可用于已验证的 Incodex 安装或恢复后的官方 `/Applications/ChatGPT.app`；不改包、不卸载。只有选择允许后才可能重置登记。跳过、关闭或中断后可重试。这不是 open 所需的终端权限。

## 示例

```bash
incodex accessibility
```

用 `incodex accessibility --help` 查看已安装版本的帮助。[窗口使用](/zh/windows/) · [权限](/zh/permissions/) · [隐私边界](/zh/privacy/)
