`inc` 和 `incodex` 是可互换的程序名。未发布实验只接受 `perm`；`accessibility` 和 `permissions` 不是命令别名。该改名不包含在稳定版 v1.4.0。

## 稳定版 v1.4.0：辅助功能检查

稳定版 v1.4.0 使用 `incodex accessibility` 或 `inc accessibility`。命令检查 ChatGPT 辅助功能，缺失时才打开共享向导。它适用于已验证的 Incodex 安装或恢复后的官方 `/Applications/ChatGPT.app`。它不改包、不卸载应用。只有在向导中选择允许后才可能重置 TCC 登记。跳过、关闭或中断后可以重试。这不是 `open` 所需的终端权限。

## 未发布实验：`perm`

运行 `incodex perm` 或 `inc perm` 检查 ChatGPT 的辅助功能与屏幕录制。命令适用于已验证的 Incodex 安装或恢复后的官方 `/Applications/ChatGPT.app`；它不改包、不卸载应用。向导将两项权限分成两行。新鲜探针未确认两项均已授权时，显式 `perm` 会打开共用引导。`unknown` 保持未知，不当作拒绝。只有新鲜探针确认两项均已授权，命令才完成。宿主或 Runtime 证据不可用时，屏幕录制保持 `unknown`，不标成已授权或已拒绝。

已授权的行仍显示本地化完成标签与 `✓` 标记（英文为 `Done ✓`）。跳过、关闭或中断后可以重试。只有选择允许才可能重置 ChatGPT 的旧辅助功能登记。屏幕录制不是 `incodex open` 的前置条件。探针和系统设置步骤见[权限指南](/zh/permissions/)。

## 示例

```bash
incodex perm
inc perm
```

用 `incodex perm --help` 查看已安装版本的帮助。[窗口使用](/zh/windows/) · [权限](/zh/permissions/) · [隐私边界](/zh/privacy/)
