`inc` 和 `incodex` 在这个命令及全部参数中通用。

```bash
incodex uninstall [--yes] [--dry-run]
```

macOS 验证并恢复匹配的官方备份，不会用旧快照覆盖已升级的官方包。Windows 只移除 Incodex 登记和观察器，不改 Store 包；移除前彻底退出 Store Codex。CLI 仍保留。

## 未发布修复：卸载后的权限引导

此行为不属于已发布的 v1.5.0 基线，真实应用验收仍待完成。macOS 恢复未修改的官方应用后，Incodex 没有屏幕录制探针。把当前 ChatGPT 应用拖入已打开的系统设置窗口只会产生回执；它不证明权限行已选中、开关已启用或权限为 `granted`。

辅助功能已授权时，引导会收回，屏幕录制仍保持 `unknown`。请检查系统设置中的当前 ChatGPT 条目。辅助功能未授权时，辅助功能操作仍可用。见[macOS 权限](/zh/permissions/)。

## 参数

| 参数 | 含义 |
| --- | --- |
| `--yes` | 跳过确认；非终端环境必须提供。 |
| `--dry-run, -n` | 预览移除计划。 |
| `--app <path>` | 仅 macOS：恢复指定 .app。 |
| `--clone` | 仅 macOS：恢复开发副本。 |

## 示例

```bash
incodex uninstall --dry-run
incodex uninstall
```

用 `incodex uninstall --help` 查看已安装版本的帮助。[窗口使用](/zh/windows/) · [权限](/zh/permissions/) · [隐私边界](/zh/privacy/)
