`inc` 和 `incodex` 在这个命令及全部参数中通用。

```bash
incodex open [--dry-run] [--mask] [--name <text>] [--avatar <local-file>]
```

用隔离的 Codex 和 Chromium home 启动官方二进制，经本地 CDP 注入同一套帽子眼镜和通知条。不复制、修改或签名应用；保留日常账号、语言和基础设置，不带入旧聊天。正常关闭清理私密会话，最小化保留。macOS 实际启动终端或启动器需要辅助功能，预览不需要。

v1.3.2 已修复：`open --mask` 支持已识别的纯头像导航侧栏，遮罩头像及关联账号菜单身份，并在等待窗口就绪时保持侧栏入口稳定。侧栏仍只显示头像，临时姓名出现在关联菜单；完整设置页仍显示官方账号资料。

## 参数

| 参数 | 含义 |
| --- | --- |
| `--dry-run, -n` | 打印目标，不开窗、不创建会话。 |
| `--mask` | 仅临时遮罩侧栏和账号菜单身份。 |
| `--name <text>` | 要求 --mask，空格需引号；未提供时随机双词名。 |
| `--avatar <local-file>` | 要求 --mask，普通 PNG/JPEG/WebP ≤5 MiB；否则离线生成。 |
| `--app <path>` | 仅 macOS：启动指定官方应用。 |

## 示例

```bash
incodex open --dry-run
incodex open
incodex open --mask --name "Quiet Otter" --avatar ./avatar.png
```
