## 安装后的入口

运行 `incodex install` 后，照常打开**官方 Codex 图标**。帽子眼镜入口位于左上角工具栏，与 Codex 标题、通知铃和 Search 同一行。

这是位置示意图，不是截图。点击帽子眼镜，或使用 macOS 的 **Shift+Command+N** / Windows 的 **Ctrl+Shift+N**。macOS 安装集成还会在官方 Dock 菜单和已有菜单栏状态菜单中加入入口。

主窗口里悬停帽子眼镜，会提示“打开私密窗口”。私密窗口里悬停会变成圆圈叉号，并提示退出；点击会关闭当前私密窗口，不会再开一层窗口。

## 可选侧栏入口

在支持该入口的布局中，左侧导航栏会显示第二个帽子眼镜入口。点击任一入口都可打开或关闭私密窗口。未显示侧栏入口时，仍可使用工具栏入口。

macOS 已验证侧栏入口可用。我们尚未在运行中的 Windows Store Codex 窗口验证该入口。

## 私密窗口

独立窗口沿用登录、语言和基础配置，不显示以前的聊天，并跟随主窗口尺寸与位置。通知条只显示在私密窗口首页，说明当前隔离会话；关闭通知条只隐藏说明，不会解除隔离。

`incodex open` 同样会显示帽子眼镜和通知条，既可以使用从未修改的官方包，也可以使用装有当前加载器的应用。

**Windows（1.5.11）：** 未启用 `--mask` 的默认私密窗口刷新页面后会恢复这些控件，同一窗口内连续刷新也可恢复。启用 `--mask` 的刷新恢复尚未验证；真实 Store 更新后的首窗恢复仍属另一项实验能力。

## 关闭和最小化

正常关窗会清理隔离 home 与 Chromium 档案。**最小化保留会话**。macOS 红色按钮关闭，黄色按钮最小化；Windows 正常关闭独立窗口即可。

崩溃、强制退出或关机可能留下待清理状态。用 [doctor](/zh/commands/doctor/) 查看，不要删除官方 `~/.codex` 数据。

## 终端菜单

在终端运行 `inc`。方向键或 `j/k` 移动，Enter 选择，数字立即执行，`V` 查看版本，`q` 退出。非终端环境不带参数时打印帮助。`inc` 和 `incodex` 是同一个程序。`--help`、`--version` 也分别支持 `-h`、`-V`。
