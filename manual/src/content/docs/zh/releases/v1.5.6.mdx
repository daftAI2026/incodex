### 更新日志
1. **macOS 替代入口**：`incodex launch` 打开带共享帽子眼镜控件的普通 Codex，复用已有集成，或通过本机 CDP 连接未修改的官方应用，不复制、改包或重签。macOS `inc` 菜单单独提供 Launch；Open 仍直接打开私密窗口。
2. **易识别的 Finder 启动器**：用户 Applications 文件夹中的 ChatGPT - Inc 使用青绿至淡紫背景的帽子眼镜图标，官方图标不变。已识别的旧 Incodex Launcher 入口会迁移到新名称。用 `incodex launch --remove --dry-run` 预览，再用 `incodex launch --remove` 只移除此入口，不关闭 Codex，也不移除应用集成、Runtime 或会话；脚本渠道的 `incodex self-uninstall` 也会清理自有入口，保留外部或修改过的入口并提示。
3. **现有窗口唤回与启动诊断**：Launch 复用普通 Codex 档案已验证的宿主，不再让第二个应用进程无声转交 Chromium。入口记住的目标保持不变。私有启动日志保留最近的目标、阶段和有界错误回执；LaunchServices 接受请求不算窗口已就绪。
4. **私密窗口生命周期**：macOS 私密窗口重载后保留共享控件和可选资料遮罩，正常关窗后销毁隔离会话。WindowServer 关窗与最小化观察不要求 CLI 或启动器的辅助功能权限；官方应用权限保持独立。重试会清除旧的启动失败提示；即使官方介绍仍挡住就绪确认，关闭私密窗口也会清理会话。
5. **会话清理**：会话宿主和 helper 已停止后，正常关窗清理可删除只读 Runtime 目录；无法确认的孤儿会话仍会保留。

升级：运行 `inc update`。兼容的注入器和动作工厂更新必须分别收到界面与动作控制器对所选代际的确认；原生变化仍须显式迁移。Launch 是 macOS 替代入口，不替代 install。CDP 分支不提供已安装 Dock/状态菜单或权限探针。Windows 保留现有官方图标集成；真实 Store 更新后的首次冷启动恢复仍属实验功能。已运行但未加载集成的 Windows 窗口不能就地修复。若 Runtime 同步报告其他安装操作留下的记录，请正常退出 Codex，先运行 `incodex uninstall`，再运行 `incodex install`；此显式迁移不算自动更新成功。未安装的 CDP 路径首次启动前，须正常退出未受启动器控制的 Codex，并保持控制器运行；从终端启动时，该终端会持续占用到普通应用退出。Runtime 启动代码变化在下次正常启动生效，不通过刷新页面迁移。
