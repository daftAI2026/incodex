## 更新内容

1. **纯头像侧栏下的遮罩窗口保持稳定**：`open --mask` 现在能够识别受支持的纯头像账号入口，遮罩其头像及关联账号菜单身份。窗口等待就绪期间，重复注入会保留侧栏控件和回调，避免已观察到的侧栏闪烁与就绪失败。
2. **修复旧 Store 包移除后 Windows 卸载受阻**：仅在确认精确包版本已不存在后，清理对应的待处理更新意图。包仍在运行、查询结果不确定或移除调试器失败时，继续保留原有安全检查。

升级方式：运行 `inc update` 更新 CLI 和共享 Runtime。本次更新不会修改或重新签名 Codex。

验证与限制：macOS 已验证 `open`、`open --mask`、侧栏悬停与关闭、关联菜单遮罩、设置往返及会话清理；Windows 也已验证遮罩窗口修复与旧包卸载修复。纯头像侧栏保留原布局，临时姓名出现在关联菜单中；完整设置页仍显示官方账号资料。真实 Windows Store 更新后的自动恢复仍属实验能力，更新后的首次冷启动仍未验证。
