本手册当前说明的稳定版是 **v1.3.1**。指南说明当前用法；下面的版本记录保留每次发布时的变化与限制。

- [v1.3.1 · 2026-10-09](/zh/releases/v1.3.1/)：macOS 启动兼容性与说明书零例外审计。
- [v1.3.0 · 2026-10-03](/zh/releases/v1.3.0/)：插件 Pin 区首位入口与命令别名通用说明。
- [v1.2.1 · 2026-10-02](/zh/releases/v1.2.1/)：启动与关闭清理、官方通知与 Tooltip、整体帽子绘制和 Windows 加固。
- [v1.1.0 · 2026-09-29](/zh/releases/v1.1.0/)：原生授权向导、布局跟随与安装兼容性。

更早的版本见 [GitHub 完整发布历史](https://github.com/daftAI2026/incodex/releases)。这里只记录实际发布的版本，不把开发分支或测试候选当作稳定版。

更新前阅读[升级指南](/zh/updates/)。通常先运行 `inc update`；需要更新应用内加载器或在官方 Codex 更新后恢复入口时，还需针对当前包重新安装集成。
