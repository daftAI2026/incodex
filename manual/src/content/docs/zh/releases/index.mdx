- [v1.5.12 · 2026-10-30](/zh/releases/v1.5.12/)：修复官方更新后 macOS 启动拒绝，并恢复侧栏首位入口。
- [v1.5.11 · 2026-10-26](/zh/releases/v1.5.11/)：Windows 私密窗口刷新恢复帽子与横幅，保留升级和迁移限制。
- [v1.5.10 · 2026-10-26](/zh/releases/v1.5.10/)：macOS 远控授权、独立钥匙串提示与新版侧栏入口。
- [v1.5.9 · 2026-10-23](/zh/releases/v1.5.9/)：跟随所选 Dock 图标，共享 Applications 启动器与旧用户目录迁移。

- [v1.5.1 · 2026-10-19](/zh/releases/v1.5.1/): 修复 macOS `inc` 别名安装、冷启动权限快照、恢复官方应用后的录屏仍未验证与升级说明。

更新前阅读[升级指南](/zh/updates/)。通常先运行 `inc update`。已登记的 macOS 默认安装会尝试在 Sparkle 更新后恢复；若入口仍缺失，请针对当前应用重新安装。Windows Store 更新仍须针对当前包代际手动安装。
