### 更新日志

1. **更新时同步 Windows 恢复组件**：CLI 更新可交接原生恢复 helper，无需常规卸载重装，并修正换包时并发启动请求互相阻塞的问题。
2. **恢复新版桌面应用的入口与提示**：侧栏入口、提示和私密窗口横幅适配官方当前模块结构，继续沿用 Codex 自身的组件和外观。
3. **修复 Windows 私密窗口无法关闭**：点击帽子或侧栏入口会正常关闭私窗并清理临时会话，普通窗口继续保留。

运行 `inc update` 更新 CLI 并发布配套 Runtime。若旧的运行中 Windows 控制器提示固定验证器无法迁移，请保存工作、正常退出 Codex，再运行一次 `inc update`，随后从官方图标打开。已经打开的私窗保留原实现，正常关闭后重开才会使用新实现。

真实 Windows Store 更新首窗的自动恢复仍属实验能力，系统安装错误尚未证明消除。已运行但未集成的窗口仍需正常退出，再针对当前包运行 `incodex install`。属于其他安装操作的待处理记录仍保留显式卸载、重装迁移路径。Windows 侧栏热挂载及两轮私窗关闭、清理已实机通过；Mac 最终同版本实机验收仍待完成。

macOS 签名和权限限制保持不变。默认安装若已因旧签名声明无法启动，更新后请正常退出 Codex，再显式依次运行 `incodex uninstall` 和 `incodex install`。`--app` 或 `--clone` 自定义目标须沿用原选项，不要重置隐私权限。注入后的包无法保留官方 `chatgpt.com` 通用链接关联。
