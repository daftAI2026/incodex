发布于 **2026-09-29** · [GitHub 原始版本说明与下载](https://github.com/daftAI2026/incodex/releases/tag/v1.1.0)

这是历史版本记录。当前稳定版见[版本索引](/zh/releases/)，实际升级步骤见[升级指南](/zh/updates/)。

## 本轮变化

- macOS 安装与卸载共用带动画的辅助功能向导，可以把应用行拖入系统设置；新增 `incodex accessibility` 检查及继续设置入口。
- 改进 macOS 私密窗口关闭和异常退出报告，最小化保留窗口。
- 帽子跟随搜索按钮的布局、颜色、缩放及 Tooltip，保留整体透明度一致的原版线条，适配更新后的首页。
- Windows 私密窗口保留官方缩放与侧栏宽度，从已安装帽子打开时沿用来源窗口的位置及尺寸，不复制聊天或账号状态。
- macOS 安装同步应用内嵌完整性信息并处理依赖框架签名，保留官方 Computer Use 组件。
- 旧版加载器也校验新增授权资源，权限引导跟随 Codex 支持的语言，错误提示提供继续设置入口。

## 发布时的已知限制

macOS 可选安装集成仍使官方 Appshot／智能快照不可用，卸载集成后恢复。后续启动与关闭修复见 [v1.2.1](/zh/releases/v1.2.1/)。
