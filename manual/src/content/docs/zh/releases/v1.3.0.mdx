## 更新日志

1. **插件 Pin 区首位入口**：在其他已固定插件上方新增帽子眼镜，保留搜索旁的工具栏入口；安装入口和独立私密窗口中的两个按钮使用相同的打开／退出动作。
2. **原生侧栏外观与恢复**：新增入口复用 Codex 按钮、Tooltip、布局和统一帽子眼镜图标，在支持的侧栏重挂载后恢复；无法安全识别布局时不显示新增入口。
3. **双语命令参考**：[公开说明书](https://daftai2026.github.io/incodex/)说明两个窗口入口，并明确 `inc` 和 `incodex` 的全部命令、参数通用。

升级方式：运行 `inc update` 更新 CLI 和 Runtime，再重新打开 Codex 加载新增入口。官方 Codex 更新后，请完全退出 Codex，再对当前包运行 `incodex install`。

已知限制：新增侧栏入口及其生命周期已在 macOS 实窗验证。本次 Windows 侧栏行为尚未完成真实应用窗口验收，目前没有可用的 Windows 测试机器；自动检查通过不能替代实窗验证。Windows Store 集成自动恢复仍为实验能力，真实 Store 更新后的首次冷启动尚未验收。macOS 的可选应用集成仍会使官方智能快照不可用，运行 `incodex uninstall` 后恢复。
