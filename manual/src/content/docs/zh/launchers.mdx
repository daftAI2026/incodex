## Finder 入口

`incodex launch` 会创建或刷新 `/Applications/ChatGPT - Inc.app`。`inc` 菜单中的 **Launch** 创建或打开普通窗口入口；**Open** 直接启动私密窗口。

在 Finder 中选择 **前往 › 前往文件夹**，输入 `/Applications` 并按回车。打开其中的 **ChatGPT - Inc.app**。

用 `incodex launch --remove --dry-run` 预览移除启动器，再用 `incodex launch --remove` 确认。此操作不卸载应用集成，也不关闭 Codex。创建、复用、移除和平台限制见 [launch 指南](/zh/commands/launch/)。

### 迁移旧用户目录入口

发布并验证共享入口后，`incodex launch` 只迁移以下精确归属 Incodex 的旧入口：`~/Applications/ChatGPT - Inc.app` 与 `~/Applications/Incodex Launcher.app`。其他用户、未知或已修改的入口会保留。旧入口无法移除时，新共享入口仍保留，CLI 会报告未迁移的路径。它不会创建 `/Applications`、回退到用户目录或请求 `sudo`。

请勿在新入口发布前手动删除旧入口。命令会先检查归属，再移除旧入口。

## 启动器图标

启动器会跟随所选 ChatGPT 或 Codex Dock 图标样式。图标资源不可用时，启动器会回退到宿主文件图标。**INCODEX** 玻璃铭牌保留在启动器上。Incodex 不复制或修改官方宿主 App。

运行 `inc update`，再运行 `incodex launch` 发布启动器。每次运行 `incodex launch`，包括打开已有入口，都会重新读取当前 Dock 图标选择。更改 Dock 选择后，再运行命令即可刷新。Incodex 不会在后台监听图标变化。更新启动器不需要重签、重装或重启宿主。即使源宿主已不存在，`incodex launch --remove` 也只会移除 Incodex 启动器，不会卸载应用集成或关闭 Codex。

## 安装快捷入口

```bash
curl -fsSL https://raw.githubusercontent.com/daftAI2026/incodex/main/scripts/setup-quick-launchers.sh | bash
```

脚本把 Raycast 命令写入 `~/Library/Application Support/Raycast/script-commands`。只在检测到 Alfred 时生成标准 `.alfredworkflow`，并打开 Alfred 正常导入确认。

## Raycast 设置

- **v2**：Settings → Script Commands → Add Script Directory。
- **v1**：Settings → Extensions → **+** → Add Script Directory。

选择上述 script-commands 目录，再运行 **Reload Script Commands**。

设置入口随 Raycast 版本变化，可对照 [Raycast 官方 Script Commands 说明](https://manual.raycast.com/script-commands)。

Open 直接启动私密窗口。Raycast 提供可用 TERM 时，Status 和 Doctor 使用 fullOutput；否则打开支持的终端。可用 `INCODEX_LAUNCHER_APP` 指定 Terminal、iTerm2、Alacritty、kitty、WezTerm、Ghostty、Hyper、WindTerm 或 Warp；指定程序启动失败会回退 Terminal。

这些快捷入口是 macOS 专用的可选配置。见[权限指南](/zh/permissions/)。

**macOS：** CLI 通过 WindowServer 观察关窗与最小化，不需要辅助功能权限。已安装宿主的权限保持独立。
