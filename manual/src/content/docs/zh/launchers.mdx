## Finder 入口

macOS 替代命令 `incodex launch` 在用户目录 `~/Applications` 创建 **ChatGPT - Inc.app**。v1.5.8 的启动器图标使用所选宿主当前的系统文件图标，并叠加 **INCODEX** 玻璃铭牌。它不跟随 ChatGPT/Codex 单独的 Dock 图标偏好设置。官方宿主包保持不变。`inc` 菜单中，**Launch** 创建或打开普通窗口启动器；**Open** 直接启动私密窗口。

## 未发布：入口将迁至 `/Applications`

此路径变更计划用于下一修订，尚未包含在 v1.5.8 中。v1.5.8 仍会在 `~/Applications/ChatGPT - Inc.app` 创建入口。下一修订将把入口发布到 `/Applications/ChatGPT - Inc.app`。

新发布器会先验证系统入口，再移除 `~/Applications/ChatGPT - Inc.app` 与 `~/Applications/Incodex Launcher.app` 中精确归属 Incodex 的旧入口。它不会创建 `/Applications`、回退到用户目录或请求 `sudo`。它会拒绝覆盖其他用户拥有的系统入口，并保留未知或已修改的同名应用。若旧入口移除失败，新系统入口仍保留，CLI 会报告未迁移的旧路径。下一修订发布前，请继续按下方 v1.5.8 路径操作。

在 Finder 中选择 **前往 › 前往文件夹**，输入 `~/Applications` 并按回车。然后打开其中的 **ChatGPT - Inc.app**。

先用 `incodex launch --remove --dry-run` 预览，再用 `incodex launch --remove` 确认移除。此操作不卸载应用集成，也不关闭 Codex。创建、复用、移除和平台限制见 [launch 指南](/zh/commands/launch/)。

## 宿主图标启动器

v1.5.8 启动器使用宿主当前的系统图标，并在底部叠加 **INCODEX** 玻璃铭牌。它不复制或修改官方 App，也不要求用户安装 Icon Composer。ChatGPT 与 Codex 保留各自标志，不再被固定图替换。

运行 `inc update`，再运行 `incodex launch` 创建或更新启动器。每次运行 `incodex launch` 或打开已有启动器，都会重新读取宿主当前的系统文件图标。宿主图标变化后，再运行命令或打开启动器即可更新。Incodex 不会在后台监听图标变化。启动器不跟随 ChatGPT/Codex 单独的 Dock 图标偏好设置，更新图标也不需要重签或重装宿主。已识别的旧启动器仍可升级或移除。即使源宿主已不存在，`incodex launch --remove` 也只会移除 Incodex 启动器，不会卸载应用集成或关闭 Codex。

## 安装快捷入口

```bash
curl -fsSL https://raw.githubusercontent.com/daftAI2026/incodex/main/scripts/setup-quick-launchers.sh | bash
```

脚本把 Raycast 命令写入 `~/Library/Application Support/Raycast/script-commands`。只在检测到 Alfred 时生成标准 `.alfredworkflow`，并打开 Alfred 正常导入确认。

## Raycast 设置

- **v2**：Settings → Script Commands → Add Script Directory。
- **v1**：Settings → Extensions → **+** → Add Script Directory。

选择上述 script-commands 目录，再运行 **Reload Script Commands**。

设置入口随 Raycast 版本变化，可对照 [Raycast 官方 Script Commands 说明](https://manual.raycast.com/script-commands)。

Open 直接启动私密窗口。Raycast 提供可用 TERM 时，Status 和 Doctor 使用 fullOutput；否则打开支持的终端。可用 `INCODEX_LAUNCHER_APP` 指定 Terminal、iTerm2、Alacritty、kitty、WezTerm、Ghostty、Hyper、WindTerm 或 Warp；指定程序启动失败会回退 Terminal。

这些快捷入口是 macOS 专用的可选配置。见[权限指南](/zh/permissions/)。

**macOS：** CLI 通过 WindowServer 观察关窗与最小化，不需要辅助功能权限。已安装宿主的权限保持独立。
