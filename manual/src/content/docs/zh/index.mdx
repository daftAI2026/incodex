Incodex 是 OpenAI Codex 桌面应用的非官方本地扩展。沿用平时的登录、语言和基础设置，开启独立对话，不带入日常聊天历史。

## 启动器图标

<figure>
  <img src="/incodex/images/launcher-icon-native-preview.png" width="240" loading="lazy" alt="叠加 INCODEX 铭牌的 ChatGPT 启动器图标" />
  <figcaption>图标示例：ChatGPT 图标加 INCODEX 铭牌。</figcaption>
</figure>

运行 `inc update`，再运行 `incodex launch`，即可创建或刷新 `/Applications/ChatGPT - Inc.app`。

启动器会跟随 ChatGPT 或 Codex 所选的 Dock 图标样式。图标资源不可用时，它会回退到宿主文件图标。更改 Dock 选择后，再运行 `incodex launch` 刷新。Incodex 不会在后台监听变化，也无须重签、重装或重启宿主。迁移与刷新步骤见 [macOS 启动指南](/zh/launchers/)。

## 从这里开始

- [安装 CLI](/zh/installation/)，随后用 `incodex open` 开窗，无须修改应用。
- 想从官方 Codex 图标进入，先[启用应用内入口](/zh/commands/install/)。
- [找到帽子眼镜并了解关窗行为](/zh/windows/)。
- [查阅全部命令](/zh/commands/)。

## 本手册的范围

本手册对应 **Incodex 1.5.10**。macOS 支持 Apple Silicon 和 Intel；Windows 支持 x86_64 与当前用户安装的 Microsoft Store Codex。暂不支持 Linux。Windows 在真实 Store 更新后的自动恢复仍属实验能力，更新后的首次冷启动尚未验证。macOS 26 权限向导仍待验证完整双行流程：在系统设置中授予缺失权限，返回已安装的 ChatGPT 窗口，并确认新鲜探针通过后向导关闭。

正常关窗会清理 Incodex 管理的本地隔离会话。这不等于取证意义上的擦除，也不能阻止文件、远程服务或连接的工具保留数据。使用前请阅读[隐私边界](/zh/privacy/)。
