## 稳定版 v1.4.0：安装路径：ChatGPT 的辅助功能

默认 `install` 会重新打开 ChatGPT 并检查辅助功能权限。已有有效权限时，无须弹授权卡；缺失时自动打开原生向导。默认 `uninstall` 也会用同一向导检查恢复后的官方应用。

![macOS 安装后自动出现的授权卡实窗截图](/incodex/images/accessibility-guide.png)

图中是中文实窗授权卡，语言跟随本地 Codex 设置。点击**允许**，把向导中的 ChatGPT 应用行拖进**系统设置 → 隐私与安全性 → 辅助功能（无障碍）**列表并开启权限，完成 macOS 认证。向导自动检查，成功后自动关闭。macOS 12 对应**系统偏好设置 → 安全性与隐私 → 隐私 → 辅助功能**。

返回可回到初始卡；跳过或关闭只留下未完成的权限设置，不撤销安装。以后运行 `incodex accessibility` 继续。只有在卡中选择允许才可能重置 ChatGPT 的旧辅助功能登记；相同 bundle ID 的应用副本共享该登记范围。`--app` / `--clone` 不触发这项自动交接。

## 未发布实验：屏幕录制

**未发布实验行为，不包含在稳定版 v1.4.0：**默认 `/Applications/ChatGPT.app` 向导并列显示“辅助功能”和“屏幕录制”两行。某项已授权时仍保留该行，并显示本地化完成标签与 `✓` 标记（英文为 `Done ✓`）。CLI 只有在新鲜探针确认两项均为 `granted` 后才报告完成。

录屏探针运行在注入到正常 ChatGPT Electron 主进程的模块中，并调用公开 API `systemPreferences.getMediaAccessStatus('screen')`。它只读取权限状态，不请求截图或录音，不重置 `ScreenCapture`，也不修改供应商 CUA 侧车。此权限与终端或启动程序的辅助功能权限分开，也不是 `incodex open` 的前置条件。

选择屏幕录制行的操作只打开 macOS 屏幕录制设置，不会授予权限。用户需在系统设置中添加或启用当前 `/Applications/ChatGPT.app`。若 macOS 要求，请正常退出并重新打开 ChatGPT。旧 ChatGPT 条目不起作用时，请手动移除旧项，再添加当前应用。

恢复官方应用或 Runtime 缺失时，探针证据保持 `unknown`；不得标成已授权或已拒绝。官方应用更新后的权限持久性仍待真机验证。

## 独立 open：终端或启动程序的辅助功能

`incodex open` 需要的是**运行命令的终端或启动程序**的辅助功能权限，用来区分关窗与最小化。这与 ChatGPT 的权限不同。开启 macOS 提示的对应程序后重试；检查发生在创建会话之前。`open --dry-run` 不请求权限。

## 钥匙串

macOS 改包后签名变化，系统可能询问应用是否可访问 **Codex Storage Key**。确认应用和项目名称匹配后，再输入 **Mac 登录密码**；希望保留授权时选择**始终允许**。允许或仅允许一次可能以后再询问；不匹配的请求选拒绝。不要把密码输入 Incodex 或 Terminal。

## 远控设备密钥

v1.3.4 起：普通已安装集成的 macOS 宿主，在官方远控模块请求系统保护、不可导出的 P-256 密钥并报 `-34018` 时，可以使用限定范围的传统登录钥匙串兼容路径。先尝试原始 Security 调用。仅硬件密钥请求、无痕窗口和 Windows 不进入此路径；官方模块及授权 API 保持原样。

兼容路径检查实际私钥不可导出，并保留系统访问控制列表，但**不保留 Secure Enclave、Data Protection Keychain 或 ThisDeviceOnly 的保护语义**。之后签名身份变化可能需要重新允许系统钥匙串访问。不会自动迁移、轮换或删除已有不可访问密钥。本地创建、读取、签名和删除已通过测试，候选 Runtime 的真实远控授权也已验证成功；重签后的钥匙串授权连续性尚未验收。

**未发布的 macOS 稳定签名实验：**兼容适配只接受原有临时签名宿主，或严格验签且叶证书匹配既有私有目录内公开证书登记的宿主。共享身份校验不授予辅助功能、Storage Key 或远控权限。每项能力保留独立检查；不新增身份库或权限服务。原生适配变化需彻底退出并重开，不能仅靠 Runtime 界面热更新。真实授权与下一次官方更新后的连续性仍是独立验收门。

## 其他权限与智能快照

钥匙串授权和 Computer Use 权限不能证明辅助功能已就绪。屏幕与系统音频录制是另一项 macOS 权限。上面的未发布实验将屏幕录制作为独立一行展示；修改它不能修复辅助功能授权。

修改后的 macOS 包无法保留有效的 OpenAI 签名。安装后官方 **Appshot／智能快照**的拍照和截图附件不可用，这不是相机权限没开。[卸载集成](/zh/commands/uninstall/)恢复官方包后可恢复；不改包的 [open](/zh/commands/open/) 路径不会改变应用签名。
